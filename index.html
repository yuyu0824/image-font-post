连接你的 GitHub 仓库

怎么连接自己的仓库？点开看教程

一、准备账号和仓库

  1. 用浏览器打开 github.com，注册并登录一个账号（记住你的用户名）
  2. 点右上角的 ＋，选 New repository
  3. Repository name 随便起个英文名，比如 xiaocangku（这就是仓库名）
  4. 一定要选 Public（公开），否则别人打不开你的链接
  5. 拉到最下面点 Create repository

二、把网站放上去

  1. 进入刚建好的仓库，点 Add file，再点 Upload files
  2. 选中 index.html 上传，然后点 Commit changes
  3. 点仓库上方的 Settings，在左边找到 Pages
  4. Branch 选 main，文件夹选 / (root)，点 Save
  5. 等一两分钟，刷新这个页面，上面会出现你的网址：https://用户名.github.io/仓库名/，以后就用它打开

三、生成令牌（相当于上传的钥匙）

  1. 点右上角头像，选 Settings
  2. 拉到最下面点 Developer settings
  3. 点 Personal access tokens，选 Tokens (classic)
  4. 点 Generate new token，选 classic
  5. Note 随便写，Expiration 选 No expiration（不过期）
  6. 下面的权限只勾 repo 这一项
  7. 拉到最下点 Generate token，把出现的那串字符马上复制，它只显示一次

四、填进来

  1. 在下面填用户名、仓库名，把令牌粘贴进去
  2. 点 保存并测试，显示“连接成功”就能用了

五、让朋友一起用

  1. 进入你的仓库，点 Settings，再点 Collaborators
  2. 点 Add people，输入朋友的 GitHub 用户名并邀请
  3. 朋友在邮箱或 GitHub 通知里点接受
  4. 朋友按第三步生成自己的令牌，在自己的设备上填：用户名和仓库名填你的，令牌填他自己的

常见问题

  • 提示令牌不对：重新生成一个，注意要勾 repo
  • 提示没有写入权限：朋友还没接受邀请，或令牌没勾 repo
  • 链接打不开：检查仓库是不是 Public
  • 刚上传的图不显示：等一两分钟再刷新
  • 令牌别发给任何人，包括别人的聊天群；万一泄露，回 GitHub 删掉它再重新生成
